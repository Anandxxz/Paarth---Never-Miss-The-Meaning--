# 🧩 Paarth — Chrome Extension

**"Never miss the meaning"** — Use Paarth anywhere on the web. Read articles, news, Wikipedia, and blogs with instant bilingual explanations, Hindi & Marathi translations, and audio pronunciation.

---

## 🚀 How to Install in Google Chrome (30 Seconds)

1. Open **Google Chrome**.
2. Go to: `chrome://extensions` (or click `⋮` Menu ➔ **Extensions** ➔ **Manage Extensions**).
3. In the top-right corner, switch on **"Developer mode"**.
4. Click the **"Load unpacked"** button in the top-left.
5. Select the `extension` folder located inside your Paarth project:
   ```
   ~/Desktop/Paarth/extension
   ```
6. **Done!** The Paarth icon will appear in your Chrome toolbar. Pin it for quick access!

---

## ✨ Features Available on Any Webpage

### 1. 🖱️ Highlight & Read Anywhere
- Select any word or sentence on **any website** (Wikipedia, Medium, BBC, The Hindu, blogs).
- A subtle floating **Paarth** pill appears right beside your cursor.
- Click it to view the **Shadow DOM Meaning Card**:
  - English contextual meaning
  - Hindi & Marathi translations
  - Phonetic spelling
  - 🔊 Audio pronunciation button
  - ★ **Save Word** to your vocabulary vault
  - 📖 **Open in Dual Reader** (sends the text directly into Paarth's bilingual reader at `http://localhost:5173`)

### 2. 📋 Right-Click Context Menus
- Highlight text on any page ➔ **Right Click**:
  - **"Explain with Paarth"**
  - **"Open in Paarth Dual Reader"**
  - **"Open Paarth Side Panel"**

### 3. 📌 Toolbar Popup
- Click the Paarth icon in your browser toolbar to:
  - Check local backend status (`Online` / `Offline`)
  - Grab whatever text you currently selected on your active tab
  - Type or paste custom sentences for instant Hindi/Marathi translation
  - Jump directly to the full Paarth web app

### 4. 🪟 Chrome Side Panel
- Opens alongside your webpage to keep translations and definitions continuously docked while reading long articles or PDFs.
